01 // FILOSOFÍA

Nuestra
identidad.

Una institución que entiende la tecnología como una herramienta para resolver problemas reales y ampliar las posibilidades de las personas.

MISIÓN

Formar talento tecnológico capaz de investigar, crear y convertir conocimiento en soluciones útiles.

VISIÓN

Ser un referente internacional de innovación interdisciplinaria con impacto humano.

VALORES

Curiosidad · colaboración · precisión · ética · servicio · valentía creativa.

02 // PANORAMA

El sistema
bajo análisis.

El FODA separa las condiciones internas del instituto de las condiciones externas que pueden abrir o limitar oportunidades.

FORTALEZAS

• Talento interdisciplinario
• Cultura experimental
• Infraestructura tecnológica
• Ecosistema de proyectos

DEBILIDADES

• Costos de investigación
• Dependencia de talento especializado
• Procesos que requieren mayor coordinación

OPORTUNIDADES

• IA y robótica
• Alianzas con industria
• Nuevos modelos educativos
• Retos urbanos y sociales

AMENAZAS

• Competencia tecnológica
• Obsolescencia acelerada
• Brechas de acceso
• Riesgos de ciberseguridad
