SFIT / GUÍA DE EJECUCIÓN

Cómo abrir y ejecutar
la página web

Proyecto académico inspirado en Grandes Héroes. Esta guía explica cómo abrir el sitio desde Visual Studio Code, comprobar sus apartados y resolver los errores más frecuentes.

1. Abre la carpeta correcta

En Visual Studio Code, selecciona Archivo → Abrir carpeta y abre:

D:\Codex\2026-10-13\ho\work\sfit-backup

Debes ver index.html, server.js, productos.html, atencion.html y la carpeta imagenes.

2. Ejecuta el servidor

Abre Terminal → Nueva terminal. Si Node.js está disponible, escribe:

node server.js

Si aparece “node no se reconoce”, utiliza la ruta del ejecutable disponible en este equipo:

$sfitNode = Join-Path $env:USERPROFILE `
  ".cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe"
& $sfitNode server.js

Esta segunda ruta pertenece al entorno local de Codex y podría cambiar. Si deja de existir, instala Node.js desde su sitio oficial y reinicia Visual Studio Code. El proyecto no requiere instalar paquetes con npm.

3. Abre el sitio

Cuando la terminal muestre SFIT disponible en http://127.0.0.1:5173, abre:

http://127.0.0.1:5173

Abrir la página local ↗

Conserva la terminal abierta mientras uses el sitio. Para detener el servidor, presiona Ctrl + C en esa terminal.

4. Revisa los apartados

  1. Estrategia: inicio, campus, misión, visión, metas y plan de acción.
  2. Organización, Forma de trabajar y Compromiso: contenido institucional y escenas animadas.
  3. Productos: diez inventos inspirados en la película, con las imágenes de imagenes, descripción, precio académico, condiciones de compra y entrega. Prueba los filtros, las fichas completas y “Solicitar información”.
  4. Atención al cliente: contacto propuesto, preguntas frecuentes, quejas, sugerencias y consulta de folios locales.

5. Prueba el formulario y el seguimiento

  1. En Atención al cliente, completa el formulario con datos de muestra y selecciona un tipo de solicitud.
  2. Marca la casilla que confirma que entiendes la demostración y pulsa “Registrar demostración”.
  3. Conserva el folio generado. Puedes descargar un comprobante en formato TXT.
  4. Introduce el folio en “Consulta tu registro” desde el mismo navegador.

El formulario funciona como demostración local. Solo guarda folio, tipo y fecha en el navegador. No envía correos ni notifica a una empresa; tampoco procesa pagos, compras o entregas. El nombre, correo y mensaje solo aparecen en el comprobante si tú lo descargas. El correo atencion@sfit.example es ficticio. El flujo de revisión y los plazos son propuestas para la actividad.

6. Capturas sugeridas para entregar

  • Catálogo con imágenes, nombres y precios; toma varias capturas para cubrir los diez productos.
  • Una ficha ampliada y la sección “Condiciones del catálogo”.
  • “Estamos para ayudarte”, con medios de contacto y preguntas frecuentes.
  • Quejas y sugerencias, pasos de atención y formulario.
  • Comprobante y consulta de un folio de demostración, usando únicamente datos de muestra.

7. Errores frecuentes

  • “node no se reconoce”: usa el comando completo del paso 2.
  • “Cannot find module server.js”: la terminal está en otra carpeta. Ejecuta cd "D:\Codex\2026-10-13\ho\work\sfit-backup" y repite el comando.
  • “EADDRINUSE”: el puerto 5173 ya está ocupado. Si esta página ya está ejecutándose, abre el enlace sin iniciar otro servidor. Detén con Ctrl + C la terminal que abrió el servidor si quieres reiniciarlo.
  • El navegador no conecta: comprueba que la terminal siga ejecutando el servidor y que la dirección sea exactamente la del paso 3. El servidor solo es accesible desde este equipo.
  • No ves un cambio: guarda el archivo y actualiza con Ctrl + F5. No necesitas reiniciar el servidor para editar HTML, CSS, JS o imágenes.
  • No aparece una imagen: confirma el nombre exacto en imagenes. No renombres los archivos sin actualizar catalogo.js.
  • No aparece un folio: usa el navegador donde lo creaste. Borrar los datos del sitio también borra sus registros locales.

8. Abrir sin servidor

Puedes abrir index.html directamente con doble clic para explorar el contenido. Para demostrar formularios y consultar folios, utiliza el servidor local: el almacenamiento puede variar entre navegadores al abrir archivos directamente.
